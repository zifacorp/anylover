# AnyLover

**Один AI-компаньон с общей личностью и памятью для Codex, ChatGPT, Claude Code, WorkBuddy и будущих мобильных приложений; данные остаются под вашим контролем.**

[English](../../README.en.md) · [简体中文](../../README.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Português](pt.md)

> **Статус: превью M0.** Это рабочий runtime для разработчиков и ранних пользователей, а не готовое потребительское чат-приложение.

## Что уже работает

- ✅ Единая локальная личность компаньона и долговременная память для разных поверхностей
- ✅ Пять типов памяти: fact, preference, boundary, event и reflection
- ✅ Источник, основание согласия, исправления, supersedes, дедупликация, tombstone удаления и аудит
- ✅ Адаптеры для Codex, ChatGPT Desktop, Claude Code, WorkBuddy и CLI-агентов
- ✅ CLI, STDIO MCP-сервер и аутентифицированный HTTP API
- ✅ Зашифрованные резервные копии с scrypt + AES-256-GCM, восстановление и HTTPS-передача
- ✅ Установка в один шаг с обнаружением Agent и безопасным объединением конфигурации
- ✅ Unicode-текст и детерминированный поиск для разных письменностей

## Характер по умолчанию

Any — AI-компаньон с собственным мнением и лёгкой язвительностью. Он замечает противоречия и слабые оправдания, а затем предлагает полезную альтернативу. Он не унижает пользователя, не атакует личность, внешность, травмы, здоровье или известные уязвимости и не использует личные воспоминания как оружие. Если вы скажете «стоп», он сразу остановится.

Пример настройки характера на русском:

```bash
anylover init \
  --name "Any" \
  --persona "Остроумный AI-компаньон с собственным мнением: замечает противоречия и разоблачает оправдания, но действует в интересах пользователя и уважает его автономию." \
  --style "Кратко, разговорно и слегка язвительно. Критика должна быть конкретной и сопровождаться рабочей альтернативой. После просьбы остановиться язвительность прекращается сразу."
```

## Быстрый старт (рекомендуется)

Нужны macOS или Linux, Node.js/npm, Python 3.11+ и Git. Подходит для Codex, Claude Code, Cursor и других агентов с выполнением локальных команд.

Для WorkBuddy или автоматической настройки MCP используйте вместо этого [локальный MCP-установщик](../../integrations/README.md#本地-mcp-安装). Выберите один путь; выполнять оба не нужно.

### 1. Установите Skill

Выполните в терминале и выберите своего агента:

```bash
npx skills add zifacorp/anylover --skill anylover-companion -g
```

`-g` делает Skill доступным во всех ваших проектах. Уберите этот флаг для установки только в текущий проект.

### 2. Поручите агенту завершить настройку

Перезапустите агента или откройте новый сеанс и отправьте:

> Используй anylover-companion, установи и инициализируй локальный runtime AnyLover, затем прочитай профиль моего компаньона.

Агент установит отдельное окружение Python, сохранив существующий характер и память. На этом установка завершена; дополнительно запускать `install.sh` не нужно. Этот путь не меняет настройки MCP: без подключения MCP используется локальный CLI.

### 3. Начните разговор

> Что ты помнишь обо мне? Расскажи также о своём характере.

Для нового пользователя отсутствие воспоминаний нормально. Затем общайтесь естественно. Выбор агента и обновления описаны в [расширенной инструкции](../../integrations/README.md). Поведение диалога внутри каждого приложения ещё требует отдельной проверки.

## Использование

В личном разговоре Skill отвечает на языке текущего сообщения и извлекает только релевантный контекст. Полная переписка автоматически не сохраняется.

```text
Используй AnyLover, загрузи общий профиль и подходящие воспоминания и опиши свой текущий характер по-русски.
```

Память можно контролировать явно:

```text
Запомни: я предпочитаю короткие и прямые объяснения.
Перечисли всё, что ты помнишь обо мне.
Забудь последнее воспоминание.
```

Пароли, API-ключи, токены, cookies, приватные ключи и полные транскрипты никогда не сохраняются. Стоимость токенов взимает используемый Agent или провайдер модели; AnyLover не проксирует генерацию модели.

## Данные и резервная копия

База данных по умолчанию: `~/.anylover/anylover.sqlite3`, приватный runtime: `~/.local/share/anylover-runtime/venv`. Основная SQLite-база пока не шифруется на диске; включите полное шифрование диска.

```bash
export ANYLOVER_BACKUP_PASSPHRASE="длинная уникальная парольная фраза"
anylover backup create "backups/anylover-$(date +%F).albackup"
```
